# dimensionality-global-heterogeneity

This repository contains code accompanying the paper 
"_Operator-valued free probability applied to recurrent neural networks with
heterogeneity in local and global circuit structures_" (2026) by Juliet Jiang, Gengshuo John Tian, and Brent Doiron. 

Some functions are identical to those found in "_Neuronal firing rate diversity lowers the dimension of population covariability_" (2026) by Gengshuo John Tian, Ou Zhu, Vinay Shirhatti, Charles M. Greenspon, John E. Downey, David J. Freedman, and Brent Doiron.

`Figures_final.m` contains code for numerical simulations (Figs. 5-10, S1-4). 
Each section can be run independently to obtain the figures it is responsible for.
